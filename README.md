# Ahmed Hamada — Cinematic 3D React Portfolio

React + Vite + Three.js + React Three Fiber portfolio built as one navigable 3D world.

## Added in this version
- Full procedural 3D developer studio in the Hero scene.
- Complete desk setup: dual monitors, keyboard, mouse, PC/server tower, lamp, cables, shelves and decor.
- Stylized 3D developer character seated at the desk with subtle head/body tracking.
- Cinematic orange/cyan spotlights, emissive practical lights, fog and light beams.
- Camera intro fly-through, pointer-based camera drift, banking, FOV breathing and scroll-driven travel through the world.
- Scroll-controlled 3D sections remain inside the same world.

## Run
```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.
